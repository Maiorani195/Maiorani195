## Projeto em destaque

### [MVault](https://github.com/Maiorani195/MVault-Backend)

API para gestão de estoque e controle patrimonial, desenvolvida com **Java, Spring Boot e PostgreSQL**.

O projeto reúne:
- Gestão de produtos, fornecedores e categorias.
- Registro de entradas e saídas de estoque.
- Autenticação com JWT.
- Validações de dados e tratamento de erros.
- Testes de autenticação e movimentações simultâneas de estoque.

É um espaço para aplicar conhecimentos de desenvolvimento backend e evoluir a implementação por meio de revisões e testes.
